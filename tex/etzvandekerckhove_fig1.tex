\abstract{We introduce the fundamental tenets of Bayesian inference, which derive from two basic laws of probability theory. \ins{We cover the interpretation of probabilities, discrete and continuous versions of Bayes' rule, parameter estimation, and model comparison.} Using seven worked examples, we illustrate these principles and set up some of the technical background for the rest of this special issue of \textit{Psychonomic Bulletin \& Review}. }
